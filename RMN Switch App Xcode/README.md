# RMN Switch App

[English overview](../README.md) · [Русское описание](../README.ru.md)

Интерфейс доступен на русском и английском. По умолчанию используется язык macOS; для остальных языков — английский. Во вкладке «Внешний вид» можно выбрать «Как в macOS», «Русский» или English. Выбор сохраняется и применяется без перезапуска; язык интерфейса не влияет на преобразование раскладки.

Версия **1.7.0 (10)**. Универсальное приложение для macOS 12 Monterey и новее (Intel и Apple Silicon), имя и идентификатор `ru.rmn.LangSwitch` сохранены.

Настройки разделены на три вкладки с иконками и подсказками: «Клавиши», «Внешний вид» и «Система». Вкладки с увеличенными иконками 22 пт расположены по центру. Ширина окна — 380 пунктов, высота подстраивается под содержимое выбранной вкладки с сохранением положения верхнего края. При отсутствии Универсального доступа сразу открывается системная вкладка. Переключение вкладки отменяет незавершённое назначение клавиш.

В настройках доступен выбор значка строки меню: «Буквы» или «Флаги». Выбор применяется сразу и сохраняется после перезапуска. Флаги России, США и Великобритании отрисовываются плоскими и полностью заполняют рамку прежнего размера 22 × 16 пунктов; цвет рамки адаптируется к оформлению macOS. Английские раскладки используют флаг США, British — Великобритании. Для языков без назначенного флага сохраняется буквенное обозначение.

Замена раскладки обрабатывает русские и латинские буквы в обе стороны в одном выделении: `ghbdtn руддщ` → `привет hello`. Регистр, пробелы и переводы строк сохраняются. Знаки внутри слова преобразуются в направлении его первой русской или латинской буквы; отдельные группы знаков используют общее направление выделения. Команда меняет все поддерживаемые буквы в выделении, включая уже правильно набранные.

При запуске Switch скрывает системный индикатор языка и восстанавливает прежнюю видимость при обычном выходе. Состояние сохраняется на случай аварийного завершения и повторного запуска.

Компактное меню содержит переключатель работы Switch, две подсказки назначенных клавиш, «Настройки Switch…» и «Завершить Switch». Системный список раскладок, эмодзи, просмотр клавиатуры и переход в настройки клавиатуры из меню удалены.

Панель без стрелки. На macOS 26+ используется системное стекло; на более ранних версиях — системный полупрозрачный фон. Флажок «Показывать название раскладки» находится в настройках рядом с выбором «Буквы / Флаги»: он меняет подпись в строке меню сразу, сохраняя прежнее значение настройки. Подпись языка в строке меню — 11 пт. Разрешение Универсального доступа и автозапуск доступны в настройках Switch.

- **Shift отдельно** — сменить раскладку выделенного текста или последнего слова.
- **Shift + ` / ~** — сменить регистр.
- **Настройки Switch…** — назначить клавиши; Esc отменяет назначение.
- **Завершить Switch** — полностью закрыть приложение.

Откройте `RMN Switch App.xcodeproj` в Xcode и выберите схему **RMN Switch App** и назначение **Any Mac** для универсальной сборки. Версия и сведения приложения находятся в общем `Info.plist`. Альтернативная сборка: `./build.sh '../RMN Switch App.app'`. Проект Xcode и скрипт используют одинаковую локальную подпись, сохраняющую разрешения между сборками. Приложение остаётся в строке меню без Dock и Cmd+Tab.

При запуске без разрешения Switch открывает свои настройки и вызывает системный запрос Универсального доступа. Доступ нужно подтвердить в macOS самостоятельно; после подтверждения обработчик включается автоматически. Статус разрешения и обработки клавиш виден в настройках. Если доступ отозван, запрос повторяется при следующем запуске.

После выдачи доступа Switch один раз предлагает автозапуск при входе в систему. Отказ сохраняется; выбор можно изменить флажком «Запускать при входе в систему» в настройках. На macOS 13+ используется SMAppService и учитывается необходимость подтверждения в системных настройках. На macOS 12 создаётся только пользовательский файл `~/Library/LaunchAgents/ru.rmn.LangSwitch.login.plist`; отключение удаляет его. Автозапуск включается только по выбору пользователя, без повторного запуска при ручном закрытии приложения. Перед включением рекомендуется установить приложение в «Программы».

Для работы требуется доступ macOS к управлению вводом: включите **RMN Switch App** в соответствующем разделе системных настроек конфиденциальности. Разрешение и состояние обработчика клавиш проверяются каждые две секунды. Отключённый обработчик включается снова; повреждённый создаётся заново. После пробуждения проверка выполняется сразу. Если macOS требует перезапуск, закройте приложение через меню и откройте снова. Для проверки выключите Punto Switcher, наберите `ghbdtn` в текстовом поле и коротко нажмите Shift: должно получиться `привет`.

Сетевых функций, истории ввода, аналитики и обновлений нет. Приложение держит только последнее слово (до 256 символов) в памяти; при переключении приложения, клике или перемещении курсора очищает его. Защищённый ввод macOS не обрабатывается. Настройки клавиш сохраняются локально.

Замена выполняется обычной вставкой; прежний буфер обмена восстанавливается, если пользователь не изменил его. В приложениях без доступного выделения используется Cmd+C; редакторы, копирующие целую строку без выделения, могут вернуть эту строку. В нестандартных редакторах и терминалах поведение требует проверки. Не вставленный и не ранее набранный текст можно изменить, выделив его. Работоспособность глобальных клавиш проверяется после выдачи разрешения macOS.

Сборка: `./build.sh`. Скрипт собирает arm64 и x86_64 и объединяет их в одно Universal-приложение; проект Xcode также собирает обе архитектуры. На macOS 12 используется прежняя панель системных настроек клавиатуры. Готовое приложение обновляется в родительской папке проекта: `../RMN Switch App.app`. Установленная копия находится в `/Applications/RMN Switch App.app`.

Для локальных пересборок закреплена постоянная подпись `ru.rmn.LangSwitch`. При переходе со старой версии один раз удалите старую запись «RMN Switch App» из «Универсального доступа» и добавьте новую копию из «Приложений». Затем обычные пересборки сохраняют ту же подпись. Это локальная подпись для собственного использования, а не сертификат Яндекса.

Диагностика `--verify-recovery` требует Универсального доступа: проверяет включение отключённого обработчика, его пересоздание таймером после повреждения и открытие настроек языков. Во время этой проверки текст не преобразуется.
