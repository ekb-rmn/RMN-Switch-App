# RMN Switch App

Приложение для macOS, которое исправляет раскладку набранного текста и меняет регистр с помощью горячих клавиш. Работает в строке меню.

## Возможности

- Исправление раскладки выделенного текста или последнего слова.
- Смена регистра и настройка горячих клавиш.
- Индикатор языка в виде букв или флага.
- Автозапуск по выбору пользователя.

Требуется macOS 12 Monterey или новее. Поддерживаются Intel и Apple Silicon. Для обработки горячих клавиш необходимо разрешение «Универсальный доступ» в системных настройках macOS.

## Сборка

На Mac с установленными инструментами разработчика Xcode:

```sh
cd "RMN Switch App Xcode"
./build.sh
```

Скрипт собирает универсальное приложение для обеих архитектур, подписывает его локальной подписью и запускает встроенную самопроверку. Результат — `RMN Switch App.app` в корне проекта.

Также можно открыть `RMN Switch App Xcode/RMN Switch App.xcodeproj` в Xcode. Подробности работы, настройки и ограничения описаны в [документации](RMN%20Switch%20App%20Xcode/README.md).

## Конфиденциальность

Приложение не содержит сетевых функций, аналитики или истории ввода. Последнее набранное слово временно хранится в памяти для исправления раскладки; настройки сохраняются локально.
